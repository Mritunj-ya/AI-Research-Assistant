# AI Research Assistant

An end-to-end AI Research Assistant built with Python, LangChain, FAISS, and open-source LLMs.

## Features

- Search research papers
- Summarize papers
- Question answering using RAG
- Research gap analysis
- Future work suggestions
- Report generation

## Tech Stack

- Python
- LangChain
- FAISS
- FastAPI
- Streamlit
- Sentence Transformers
